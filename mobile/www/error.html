Can't reach the vibed server

The Android app loads your Next.js app from the host machine. Fix these, then rebuild:

  1. On your PC run npm run dev (port 2000).
  2. Sync for emulator: npm run mobile:sync:android
  3. Rebuild / Run in Android Studio.
  4. Emulator URL must be http://10.0.2.2:2000 (not localhost).
